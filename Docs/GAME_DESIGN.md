# 游戏设计

《漂海牧场：Driftstead》是一段明亮的 2.5D 海上生存建造 Demo。玩家用蓄力抛钩打捞漂流物，在 6×4 空间背包中整理不同尺寸的物品，再将资源投入设施与木筏升级。

## 核心循环

1. 在海面观察并瞄准漂流物。
2. 按住/松开左键决定抛钩距离，右键或 Space 提前回收。
3. 在背包中拖拽、旋转、拆分、合并物品；满载物进入临时回收篮。
4. 在工作台开桶、升级，或使用种植田、雨水桶、交易码头等设施生产资源。
5. 从 4×4 漂流木台扩建为 10 级、3 层的海上绿洲城，并点亮灯塔。

## 成长节奏

- 1–3 级：打捞、背包、基础生产。
- 4–6 级：开放二层、储物和交易。
- 7–9 级：开放三层、动力、淡化和自动回收。
- 10 级：完整海上牧场与灯塔目标。

普通模式通过任务链教授完整循环；展示模式直接提供十级木筏和测试资源，并使用独立存档槽，方便演示和截图。
