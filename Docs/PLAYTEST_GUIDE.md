# 漂海牧场：第一段航程

这是单人、中文、固定斜俯视的海上生活 Demo。本轮重点是从小木筏起步，到登上二层、修复求救信标的一段完整航程。

## 开始

将试玩 ZIP 完整解压，在 Windows 文件夹中双击 Driftstead.exe，不要只复制一个 exe。主菜单选择“开始新的航程”；“继续上次航程”读取已有进度；“参观十级牧场”为独立展示模式。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 瞄准 | WASD / 鼠标 |
| 蓄力抛钩 | 按住左键至少约 0.15 秒，再松开；蓄满约 1.2 秒 |
| 提前收钩 | 右键或空格 |
| 开木桶、取水、种植、爬楼梯、修复信标 | 靠近后按 E |
| 扩建木筏 | 靠近工作台按 U |
| 背包 | Tab；左键拖放，R 旋转，Shift+R 拆分，B 从临时篮放回 |
| 保存 / 暂停 | F5 / Esc；背包打开时 Esc 先关闭背包 |
| 返回主菜单 | Esc 后点击“保存并返回主菜单”，或在暂停面板按 M |
| 快速补给 | 游戏中每按一次 F1，木材、绳索、金属、布料、种子、食物、淡水、零件、电力各 +100 |

去程不会碰到东西就缩回；回程会带上沿途的多件合格物资，到人物脚下才装入背包。背包满时物资进入临时回收篮。

F1 补给直接加入资源余额，不占背包格子；可以重复按，按住不会持续发放。主菜单和暂停时不发放，返回游戏再按即可。补给后可按 F5 保存进度。

## 首段目标

跟随左上角章节：打捞 6 件物资 → 在工作台开桶 → 扩建二级并取水 → 三级播种，等待 45 秒成熟 → 扩建四级、使用木梯上二层 → 备齐右侧提示的资源，修复信标。

建造资源在打捞时自动计入顶部；背包中的实物不是额外重复兑换入口。密封木桶需要在工作台打开。升级前可查看缺少的材料，不会因材料不足而被扣走已有资源。

建议按 20–30 分钟体验目标试玩，但这不是经过新玩家计时验证的通关时长。五级以上可自由扩建，不属于本轮重点平衡范围。

## 存档与反馈

直接 F5 保存需等钩子和物资回到脚下。暂停菜单的“保存并返回主菜单”会自动先收钩、再保存；失败时保留当前场景，不会强制退出。返回后选择“继续当前航程”可恢复原位置和原模式。开始新航程不会立即删除旧档，下一次保存会替换当前进度并保留上一份有效备份。

背包中的图标来自场景物资的真实模型与材质，点击可看大图和物资信息。种子箱、机械箱和动物箱共用木箱外观，请以中文名称为准。

## 小岛与沉船

远处小岛和沉船目前是环境布景，不可登陆、采集或搜刮，也不是任务目标。本版主要活动范围是木筏与周围可打捞的漂流物；扩建后可经木梯探索木筏上层。

遇到问题时记下当时的等级、任务、操作和现象，保留 Saved/Logs 中的游戏日志。不要为了排查问题先删除存档。

角色目前是带轻微动态的低多边形静态模型，尚非完整骨骼动画；界面使用中文 Canvas HUD。免费美术许可见项目 Docs/ART_CREDITS.md。
